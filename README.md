# ATM Interface System

## Description

ATM Interface System is a Java-based console application that simulates basic ATM operations. The system allows users to log in securely and perform banking activities such as balance inquiry, cash deposit, cash withdrawal, and viewing transaction history through a menu-driven interface.

## Features

* User Authentication (Login)
* Balance Inquiry
* Cash Deposit
* Cash Withdrawal
* Transaction History
* Secure Logout

## Technologies Used

* Java
* Object-Oriented Programming (OOP)
* Scanner Class
* Conditional Statements
* Loops

## How to Run

1. Clone the repository.
2. Open the project in any Java IDE (Eclipse, IntelliJ IDEA, VS Code).
3. Compile and run the Java file.
4. Login using the provided credentials.
5. Perform ATM operations through the menu.

## Learning Outcomes

* Understanding Java fundamentals
* Implementing OOP concepts
* Developing menu-driven applications
* Handling user input and validation
* Simulating real-world banking operations
